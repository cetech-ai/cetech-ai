# Cyan Eclipse Technologies

## About

Cyan Eclipse Technologies LLC is a software company based in Tallahassee, Florida, founded in 2024. We are an SBA VetCert-certified Veteran-Owned Small Business (VOSB).

Our work covers three areas:

- **Custom software engineering** — web platforms, internal tools, and integrations
- **Software testing & QA** — verification, conformance testing, and quality evidence
- **AI-agent infrastructure** — Model Context Protocol (MCP) tooling that lets AI agents read, verify, and transact safely

## The White Report

[The White Report](https://thewhitereport.com) is our media property covering crypto and AI news. It is built for two audiences at once: human readers, and AI agents. Every article ships with a structured JSON twin, and the site runs a live MCP server so agents can read our reporting and our graded prediction scoreboard directly.
